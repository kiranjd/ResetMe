# ResetMe

Claude and Codex usage, reset history, and local Codex prompting patterns at the top of your screen. Free and open source. [Website](https://kiranjd.github.io/ResetMe/).

https://github.com/user-attachments/assets/804f7c07-c4d0-412f-8b40-923316693e0c

## Download

[Download ResetMe for Mac](https://github.com/kiranjd/ResetMe/releases/latest/download/ResetMe.dmg)

macOS 14+ · Apple silicon · An existing Codex or Claude Code sign-in

Hover at the notch or the top center of an external display. The 14-day history distinguishes quota resets from banked-reset arrivals, with dates on hover. Prompting shows seven days of local Codex activity.
